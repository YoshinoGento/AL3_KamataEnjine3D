# 11月分進捗
## 操作方法
WASDで移動。スペースでジャンプ。  
マウスで狙ってクリックで射撃  
敵を全て倒すとゴール出現
## 今月の成果一覧
- ロックオン機能の変更
  - ワールド座標でとっていたマウスの座標をスクリーン座標にすることによって敵のロックオンをしっかりとることができた。
- ミサイルの軌道の変化
  - 今まではミサイルの起動を弧を描く感じにしていたがよりミサイルに見えるように
- ロックオン時のレティクルの表示
  - ロックオン時に分かりやすいようにレティクルを表示した。敵の大きさによってレティクルの大きさが変わるようにした。
## その他
敵に追尾をしてるのですが、追尾力を強くしすぎてプレイヤーのの周りを永遠に回ってるようになってしまう。

# 10月分進捗
## 操作方法
WASDで移動。
スペースで通常弾。
右クリック⇒ロックオン
左クリック⇒ミサイル発射
## 今月の成果一覧
- 移動方法を設定する
  - 上下左右で動けるように設定した、移動範囲設定もした。
- 通常弾を追加
  - スペースで通常弾を発射できるようにした。ある程度飛んで行ったら消える処理もした。
- ミサイルを追加したい
  - 発射する時に敵がいた場所に行くようにした。
- ロックオン追加
  - ロックオンを追加してミサイルの飛んでいく敵を指定できるようにした
## その他
敵を増やしてロックオンを複数の敵にしようとしたが、マウスの座標をワールド座標でとっていたため敵が真ん中に以外の敵がロックオンできなかった。
